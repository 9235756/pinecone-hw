# VPg02 — Векторная память на Pinecone

Домашнее задание «VPg02. Архитектуры хранения данных». Цель: настроить индекс Pinecone, подключить embedding-модель, загрузить 22 фразы об автомобилях и брендах и проверить поиск по смыслу.

## Стек

- Python 3.11+
- OpenAI `text-embedding-3-small` (1536 измерений) через [ProxyAPI](https://proxyapi.ru)
- Pinecone serverless: metric `cosine`, dimension `1536`, AWS `us-east-1`
- aiogram 3 — бонусный Telegram-бот
- python-dotenv, numpy


## Запуск

Окружение:

```bash
# macOS / Linux
python3 -m venv .venv && source .venv/bin/activate && pip install -r requirements.txt
```

```powershell
# Windows (PowerShell)
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

Скопируйте `local.env.example` в `local.env`, впишите ключи `PROXYAPI_KEY` и `PINECONE_API_KEY`, затем:

```bash
cd src
python 01_create_index.py
python 02_test_embedding.py
python 03_upsert.py
python 04_search.py
python 05_bot.py   # опционально, нужен TELEGRAM_BOT_TOKEN
```

### Режимы

| `MOCK` | Что происходит | Куда пишутся отчёты |
|---|---|---|
| `1` | Эмуляция без ключей: псевдо-эмбеддинги из хэшей первых 5 букв слова, in-memory индекс с косинусной близостью | `reports/mock/` |
| `0` | Реальные ProxyAPI (OpenAI Embeddings) и Pinecone serverless | `reports/real/` |

Типовые ошибки в режиме `MOCK=0`: `401 Unauthorized` — неверный ключ; `Dimension mismatch` — удалите индекс в консоли Pinecone и создайте заново с dim=1536; пустые `matches` — подождите 10 секунд после upsert и повторите шаг 04.

## Выводы

- **Вектор против слов.** Поиск по словам находит только буквальные совпадения. Семантический эмбеддинг сводит «лес и грязь» к «бездорожью», а «на электричестве» к «электромобилям», хотя общих слов почти нет.
- **Как читать score.** Это косинусная близость: выше 0.55 — уверенное совпадение, 0.40–0.55 — тематически близко, ниже 0.40 — скорее шум.
- **Mock против real.** Офлайн-прогон ловит только общие корни: «экономичная» → Kia Rio срабатывает (0.51), а на запрос про электричество первым выходит Toyota Prius — из-за общего слова «автомобиль», а не смысла. В выдаче mock много одинаковых score и случайных соседей.
- **Итог.** Mock проверяет, что конвейер «эмбеддинг → upsert → query → отчёт» собран верно, а качество смыслового поиска обеспечивает только настоящая embedding-модель.
